# Pocket Pixel 64 — Lospec palette pack

This source update includes the exact hex values of eight artist-created palettes published on Lospec, plus the original RGB64 palette. They are embedded in the executable at compile time; no PSP internet connection is required.

Press **Circle** to cycle between palettes; **L/R** changes the selected color within the active palette. **X** draws, **Square** erases. Start saves artwork plus the selected palette; Select loads it. Existing PP64 art files remain readable.

**Note:** Changing palettes recolors the existing image using its saved color indices. For now, choose your palette before starting a drawing. No PNG export yet. This is PSP SDK source, not a compiled EBOOT.PBP; it has not been hardware tested.
